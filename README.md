# Futuristic Cyberbrick Robotic Arm
This is a 3D printable robotic arm designed in Autodesk Fusion for the CyberBrick platform. It uses three servo motors, a gearbox for 360-degree base rotation, and a two-sided geared claw controlled by one servo. The arm is designed to be lightweight so the CyberBrick servos can move it smoothly. This project is futuristic because it combines 3D printing, robotics, and programmable movement into a compact robotic arm.


# Assembly Instructions
1. Take the base of the robot and sand down the axle to make it smoother. Also burn off the stringing from the 3D Print if there is any.

<img width="840" height="597" alt="Screenshot 2026-08-20 at 8 45 54 PM" src="https://github.com/user-attachments/assets/9bfc82c8-8468-4f6e-a33f-e6772c5f3108" />

3. Place the gearbox into the provided slot on the robot platform and put the platform on top of the base, making sure the gear lines up with the base.
<img width="840" height="714" alt="Screenshot 2026-08-20 at 8 48 17 PM" src="https://github.com/user-attachments/assets/93562abb-942b-4760-990b-8da944c2f826" />

4. Screw in the Reciever Module on the printed standoffs on the Robot Platform. Use 4x M2.5 screws provided in the Cyberbrick Kit.

5. Install the battery in its provided slot on the robot platform. Connect the gearbox wires and the battery wire to the marked location on the Reciever Board.

6. Take one 360 degree Servo Motor provided in the Cyberbrick Kit and screw it onto the 1st servo arm using 2x M2.5 screws.
